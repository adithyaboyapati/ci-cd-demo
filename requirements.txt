# requirements.txt — Production Dependencies
# ===========================================
#
# WHY PIN EXACT VERSIONS?
# "It works on my machine" is almost always a version mismatch.
# Pinning exact versions guarantees that:
#   - Your local environment = the CI environment = the production container
#   - A dependency update (e.g. flask 3.0.1 → 3.1.0) doesn't silently break
#     things. It must be an intentional, reviewed change.
#
# HOW TO UPDATE VERSIONS:
#   pip install --upgrade <package>
#   pip freeze > requirements.txt
#   → Then your CI tests validate the upgrade is safe before it ships.
#
# WHY SEPARATE requirements.txt AND requirements-dev.txt?
# The production Docker image should be as small as possible.
# pytest, flake8, coverage tools are NOT needed in production.
# Smaller images = faster deployments, smaller attack surface.
